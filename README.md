# ДЗ-бот (aiogram)

Telegram-бот для группы: супер-админ назначает людей, которые могут добавлять
домашние задания, остальные — смотрят ДЗ по предметам, а внутри предмета —
по датам добавления.

Список предметов зашит в `bot/constants.py` (`SUBJECTS`) и засевается в базу
при первом запуске. Чтобы изменить набор предметов — поправьте список и
перезапустите бота (новые предметы добавятся, существующие не тронутся).

## Роли

- **Супер-админ** — задаётся в `.env` через `SUPER_ADMIN_IDS`. Может назначать
  и снимать «админов» (кнопка «👤 Управление админами»).
- **Админ** — добавлен супер-админом, может добавлять ДЗ (кнопка «➕ Добавить ДЗ»).
- **Все остальные** — только просмотр ДЗ по датам («📚 Посмотреть ДЗ»).

## Запуск

1. Создать бота через [@BotFather](https://t.me/BotFather), получить токен.
2. Узнать свой Telegram ID (например, через [@userinfobot](https://t.me/userinfobot)).
3. Скопировать `.env.example` в `.env` и заполнить:
   ```
   BOT_TOKEN=<токен от BotFather>
   SUPER_ADMIN_IDS=<ваш Telegram ID>
   ```
4. Установить зависимости:
   ```bash
   python -m venv .venv
   source .venv/bin/activate
   pip install -r requirements.txt
   ```
5. Запустить:
   ```bash
   python -m bot.main
   ```

База данных SQLite создаётся автоматически в `bot/database/homework.db`.

## Запуск в Docker

Нужен настроенный `.env` (см. выше). Файл `bot/database/homework.db` (если
уже существует локально, с данными) и `.env` не копируются внутрь образа —
они подключаются как volume, поэтому:
- секреты не попадают в слои образа;
- база данных переживает пересборку и перезапуск контейнера.

```bash
docker compose up -d --build
```

Автоперезапуск обеспечивает `restart: unless-stopped` в `docker-compose.yml`
— контейнер поднимется сам после падения бота или перезагрузки сервера,
если только его не остановили вручную.

Полезные команды:
```bash
docker compose logs -f        # логи бота
docker compose restart        # перезапуск (например, после обновления .env)
docker compose up -d --build  # пересобрать и перезапустить после git pull
docker compose down           # остановить и убрать контейнер (база не удаляется)
```

## Как добавить админа

Супер-админ нажимает «👤 Управление админами» → пересылает боту любое
сообщение нужного человека (или присылает его числовой Telegram ID) →
пользователь становится админом и получает возможность добавлять ДЗ.

## Как добавить ДЗ

Админ нажимает «➕ Добавить ДЗ» → выбирает предмет из списка → вводит текст
задания → опционально прикладывает фото/файл → подтверждает. Задание сразу
появляется в «📚 Посмотреть ДЗ»: предмет → дата → карточка задания.

## Очередь на метаязыки

Для предмета «Социогуманитарные метаязыки познания» есть отдельная механика
записи на занятия. Число тем и занятий задано константами в
`bot/constants.py` (`META_TOPICS_COUNT = 7`, `META_SESSIONS_COUNT = 3`).

- Всего 7 фиксированных тем. У каждой темы — 3 слота-занятия («Занятие 1» —
  ближайшее, «Занятие 2», «Занятие 3»). Получается грид 7×3, в каждой ячейке
  своя очередь, в неё может встать сразу несколько человек.
- Пользователь через кнопку «📋 Очередь на метаязыки» выбирает тему → занятие
  → встаёт в очередь и видит свою позицию. Одновременно можно быть только в
  одной ячейке (тема+занятие) — чтобы сменить, сначала нужно выйти («🚪 Выйти
  из очереди»).
- Когда админ добавляет новое ДЗ по этому предмету, бот считает это
  признаком «занятие 1 прошло» и **автоматически сдвигает очередь**: очередь
  на Занятие 1 удаляется (эти люди уже отзанимались), Занятие 2 становится
  Занятием 1, Занятие 3 — Занятием 2, и открывается новое пустое Занятие 3.
  Сам список тем (7 штук) при этом не меняется.

## Структура проекта

```
bot/
  main.py              # точка входа
  config.py            # загрузка .env
  constants.py          # список предметов (SUBJECTS)
  database/
    db.py              # инициализация SQLite + сев предметов
    requests.py         # CRUD-функции
  filters/roles.py      # фильтры IsAdmin / IsSuperAdmin
  states/states.py       # FSM-состояния
  keyboards/             # reply- и inline-клавиатуры
  handlers/
    common.py            # /start, отмена
    student.py           # просмотр ДЗ: предмет → дата → задание
    admin.py              # добавление ДЗ (FSM), создание тем метаязыков
    superadmin.py          # управление админами
    queue.py               # очередь на темы метаязыков
```
